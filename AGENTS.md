# Repository language

- Write all project-owned documentation, source code, comments, docstrings, new identifiers, interface labels, tooltips, errors, logs, examples, filenames and screenshot text in English.
- Use English for commit messages, pull request descriptions and repository metadata.
- Preserve existing public node IDs, API keys and serialized fields when compatibility depends on them.
- Preserve user-authored prompts, dialogue, titles, media filenames and saved projects exactly as supplied, regardless of language. Do not translate user content automatically.
- Keep third-party attribution and license notices intact.
- Keep documentation examples and screenshots consistent with the current English interface.
